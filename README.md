# Billetera Virtual

Este workspace reúne seis repositorios Git independientes y los recursos compartidos de desarrollo. La rama `workspace-integration` de Billetera-Virtual conserva Docker Compose, documentación, scripts y contratos compartidos. El frontend sirve la demo en `http://127.0.0.1:8080`. Los cinco backends ejecutan comprobaciones de configuración desde sus propios repositorios o con Compose.
